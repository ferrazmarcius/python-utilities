# 🛒 Projeto Lista de Compras em Python

Projeto desenvolvido no âmbito dos cursos e bootcamps (DIO), com o objetivo de praticar a lógicas de programação em **Python** e a gestão de código com **Git e GitHub**.

---

## 🚀 Funcionalidades
- **Adicionar itens:** Permite inserir novos produtos na lista de compras.
- **Visualizar lista:** Exibe todos os itens atualmente registados.
- **Remover itens:** Possibilidade de eliminar produtos indesejados da lista.
- **Organização modular:** Código estruturado para facilitar a leitura e manutenção.

---

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 🐍
- **Controlo de Versões:** Git & GitHub (com autenticação SSH) 🔐
